# 宏斯特机电 — 飞书多维表格系统

## 表格结构

| 表名 | 用途 | 主要字段 |
|------|------|---------|
| **客户管理** | 客户信息库 | 客户名称、行业、规模、对接人、接单累计金额、客户阶段 |
| **抓住机会** | 销售机会跟踪 | 项目名称、分类、项目阶段(7级)、客户预算、负责人、关联客户 |
| **在制订单** | 执行中的项目 | 同左 + 完成度(进度条) |
| **售后维保** | 验收1年内维保 | 项目名称、开始日期、到期日、状态、负责人 |
| **结案** | 已完结项目归档 | 项目名称、结案日期、项目总结、归档人 |

## 使用说明

### 首次使用
```bash
cd feishu-bitable
npm run init    # 创建表格结构（已完成）
npm run seed    # 填充演示数据（已完成）
```

### 日常使用
```bash
# 中标项目 → 自动转入在制订单
npm run transfer
```
